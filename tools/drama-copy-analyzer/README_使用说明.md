# 短剧文案拆解工具·加强版（Windows 本地）

面向短剧、短视频创作者和对标拆解用户。粘贴别人的文案或自己的草稿，可快速查看钩子、结构、冲突、情绪、句段节奏、高频词、金句、本文模板和针对性改写建议。

加强版新增两个核心卖点：

1. **短剧剪辑老师式批改**：A–H 不只给统计和标签，会尽量点名原文句子，告诉用户“好在哪 / 弱在哪 / 怎么改一句更好”。
2. **一键改写稿**：点击 `生成改写稿`，用本地规则 + 模板启发式重排钩子、冲突、反转、收尾，输出一篇完整可试拍口播稿，并列出相对原文的关键改动。

## 交付定位

正式卖给买家时，推荐交付 **Windows 绿色包**，不是 Python 源码目录。

买家收到：

```text

```

解压后主要看到：

```text
DramaCopyAnalyzer_Windows\

├─ _internal\                 PyInstaller 运行文件，不能删除

```

买家 **无需安装 Python、无需 pip、无需注册账号**。解压完整文件夹后，双击 `DramaCopyAnalyzer.exe` 即可使用。

- 当前版本完全本地运行。
- 不调用远程 API。
- 不上传用户粘贴或导入的文案。
- 不使用云端大模型。
- 一键改写稿由本地规则 + 模板拼装生成。
- 没有许可服务器、账号验证或“手机回家”逻辑。

## 买家怎么用

1. 解压 `DramaCopyAnalyzer_Windows.zip`。
2. 保留整个 `DramaCopyAnalyzer_Windows` 文件夹，不要只把 exe 单独拖出去。
3. 双击 `DramaCopyAnalyzer.exe`。
4. 左侧粘贴文案，或导入 `.txt / .md`。
5. 第一次可点 `试拆示例`，会自动载入样例并完成 A–H 拆解。
6. 粘贴自己的文案后点 `开始拆解`。
7. 需要完整试拍底稿时，点 `生成改写稿`。
8. 需要保存时导出 `.md` 或 `.txt` 报告；报告会自动包含 A–H + 一键改写稿 + 关键改动说明。

详细买家说明见 `买家使用说明.txt`。

## 加强版 A–H 功能

### A. 开头钩子

读取前 1–3 句，给 0–100 分，并判断悬念、冲突、利益点、情绪。

加强版会额外点名第一句，给出类似：

```text
原句：「……」
判断：这个开头能不能用
怎么改一句更好：把什么提前 / 把什么删掉
```

重点看短剧前 3 秒，不写论文式长分析。

### B. 结构标注

按内容特征判断 `钩子 / 铺垫 / 冲突 / 反转 / 催行动作`。

**不会因为它是第一段就强制标成钩子。** 纯人物背景、工作生活交代等开场会优先判为铺垫；明显无法归类的段落会显示 `弱/缺失`。

加强版会对每个被标注段落再补一句老师批改，例如：这段为什么只是铺垫、冲突代价够不够、反转前要不要埋伏笔。

### C. 冲突点列表

列出文中的对立、压力、转折句，并说明为什么构成冲突。

加强版会强调“这句能不能直接拍成冲突镜头”，优先看谁对谁做了什么、失败会失去什么。

### D. 情绪起伏

按句标 `正向 / 负向 / 紧迫 / 中性`，并给出前紧后松、前缓后紧、整体偏平等节奏描述。

加强版会直接指出：中性句是不是太多、反转有没有形成情绪峰值、冲突前是否需要留一点安静段。

### E. 句段节奏

统计总字数、句数、平均句长、短句占比、长句占比、段落数，并判断是否过碎或过长。

加强版会点名最长句，提醒哪里适合拆成“动作一句 + 后果一句”，更贴近口播和字幕剪辑。

### F. 高频词 Top10 + 金句候选

提取高频中文词/短语，并从原文选 3–5 条可单独用于封面、标题或卡点字幕的句子。

加强版会提醒：高频词只是这篇反复在讲什么，不等于这些词本身有流量；封面优先挑有结果、反差、身份差或问题感的句子。

### G. 可复用模板

不是固定空白模板。会根据本次原文抽取：

- 主角姓名
- 对手/阻力方
- 开头钩子原句
- 核心冲突原句与冲突动作
- 关键反转原句与反转证据/机制
- 收尾原句

再基于这篇文案生成结构链和复用提纲。

加强版会明确提醒：复用的是“人物关系 + 冲突动作 + 反转证据 + 收尾问题”的信息顺序，不是让用户照抄原文。

### H. 改写建议

每次输出 3–8 条。每条都包含：

```text
原句：具体引用本文句子
怎么改：针对这句话给动作
为什么：说明修改理由
```

不是只给“加强冲突”“提高节奏”这种空话。

## 一键改写稿

界面新增按钮：

```text
生成改写稿
```

点击后会：

1. 从原文前 1–3 句判断当前钩子是否够强。
2. 如果开头太弱，启发式提前冲突或反转信息做新钩子。
3. 把最强冲突句尽量前置并单独成段。
4. 对过长冲突句做“动作一句 + 后果一句”的口播拆句。
5. 把明确反转留到后段单独兑现，并根据需要加“可下一秒”等转折口播连接。
6. 去掉一部分常见赘词。
7. 优化结尾，尽量保留一个未解问题，不堆多个平台 CTA。
8. 输出完整改写稿和 `相对原文的关键改动`。

输出格式：

```text
【完整改写稿｜可直接试拍】
……完整口播稿……

【相对原文的关键改动】
1. 钩子：……
2. 冲突：……
3. 反转：……
4. 收尾：……
```

这是 **规则 + 模板启发式改写**，不是云端 AI，不调用远程 API、不上传文案。优点是完全本地、速度快、隐私边界清晰；缺点是不会像大语言模型一样真正理解所有隐喻和复杂人物关系，所以试拍前仍建议人工微调。

## 导出报告

导出 `.md` 或 `.txt` 时，报告会自动包含：

- 原文
- A–H 八模块老师式批改
- 一键改写稿
- 相对原文的关键改动
- 本地规则/启发式免责声明

即使用户没有提前点 `生成改写稿`，导出时也会自动生成改写稿并一并写入报告。

# 卖家出包

## 方案 A：本机一键出绿色包

卖家打包电脑需要安装 Python 3.10+。这是 **卖家打包依赖**，买家不需要 Python。

在 `tools\drama-copy-analyzer\` 目录直接双击：

```text
build_release.bat
```

或命令行：

```bat
build_release.bat
```

脚本会自动执行：

1. 创建隔离的 `.build-venv`。
2. 安装 `requirements-build.txt` 中的 PyInstaller。
3. 运行 `self_check.py`。
4. 用 `drama-copy-analyzer.spec` 打包。
5. 组装买家绿色文件夹。
6. 对打包后的 `DramaCopyAnalyzer.exe --self-check` 做一次冒烟验收。
7. 生成最终 ZIP。

成功后产物：

```text
tools\drama-copy-analyzer\release\DramaCopyAnalyzer_Windows\
tools\drama-copy-analyzer\release\DramaCopyAnalyzer_Windows.zip
```

**闲鱼交付优先发：**

```text
release\DramaCopyAnalyzer_Windows.zip
```

如果脚本任何一步失败，会直接中止并提示不要交付当前产物。

## 方案 B：GitHub Actions 自动出包

当前分支和 PR 会运行：

```text
Drama Copy Analyzer Windows Build
```

CI 会在 Windows 环境：

1. 编译 Python 文件。
2. 跑完整 `self_check.py`。
3. 安装 PyInstaller。
4. 生成 `dist\DramaCopyAnalyzer\`。
5. 执行打包后 EXE 自检。
6. 组装并压缩 `DramaCopyAnalyzer_Windows.zip`。
7. 上传 GitHub Actions Artifact：

```text
DramaCopyAnalyzer_Windows
```

Artifact 内包含：

```text
DramaCopyAnalyzer_Windows.zip
DramaCopyAnalyzer_Windows.zip.sha256.txt
```

所以卖家即使不在自己电脑打包，也可以从成功的 CI 运行里下载 Windows 成品再做人工验收。

## 源码开发运行

如果只是自己改代码，可以双击：

```text
run.bat
```

或：

```bat
py -3 main.py
```

源码运行才需要 Python；这不是给普通买家的交付方式。

## 自检

源码目录运行：

```bat
py -3 self_check.py
```

当前自检会锁定：

- A–H 八模块都有内容
- A–H 都包含老师批改层，不退化成纯统计表
- B 纯背景首段不能被强制判成钩子
- G 必须从样例抽到具体人物、冲突、反转，不能退回固定 `【___】` 模板
- H 每一条建议必须引用原文
- `生成改写稿` 对应本地函数必须生成非空完整稿
- 改写稿必须包含 `完整改写稿` 与 `相对原文的关键改动`
- 新文案分析结果和改写稿都要变化
- MD/TXT 报告包含 A–H + 一键改写稿
- 高频词重复提取
- README、买家说明、GUI、一键出包脚本存在关键交付信息

## 正式售卖前最后人工验收

即使 CI 全绿，也建议把 `DramaCopyAnalyzer_Windows.zip` 拿到一台 **没有安装 Python** 的 Windows 10/11 电脑或干净虚拟机中测试：

1. 双击 EXE 能打开。
2. 点“试拆示例”A–H 都有老师式批改结果。
3. 点“生成改写稿”能得到非空完整稿和关键改动。
4. 粘贴一篇新中文文案，分析结果和改写稿都会变化。
5. 能导出 MD/TXT，报告里有 A–H + 改写稿。
6. 关闭软件再开，不报错。

当前没有商业代码签名证书，因此 Windows 可能显示“未知发布者/SmartScreen”提示。正式大规模售卖若希望降低拦截率，需要后续购买代码签名证书并给 EXE 签名。
