短剧文案拆解工具｜买家使用说明

【你收到的是什么】
这是 Windows 本地版绿色软件。解压后直接使用，无需安装 Python，也不需要注册账号。

【怎么打开】
1. 把整个 DramaCopyAnalyzer_Windows 压缩包解压到电脑任意普通文件夹。
2. 不要只把 exe 单独拖出来，整个文件夹要一起保留。
3. 双击 DramaCopyAnalyzer.exe 启动。

【怎么用】
1. 在左侧大文本框粘贴短剧/短视频文案；也可以点“导入 .txt / .md”。
2. 第一次可直接点“试拆示例”，软件会自动载入样例并完成拆解。
3. 点“开始拆解”，右侧 A–H 八个分页会显示结果。
4. 需要保存时，点“导出报告 .md”或“导出报告 .txt”。

【八个模块】
A 开头钩子
B 结构标注
C 冲突点列表
D 情绪起伏
E 句段节奏
F 高频词 Top10 + 金句候选
G 根据本文生成的可复用模板
H 引用原文具体句子的改写建议

【隐私】
当前版本完全本地分析，不调用远程 API，不上传你粘贴或导入的文案。

【打不开时】
1. 确认已经完整解压，不要在压缩包预览里直接运行。
2. 确认 DramaCopyAnalyzer.exe 旁边的程序文件夹内容没有被删掉。
3. 如果 Windows 提示“未知发布者”，这是因为当前版本没有商业代码签名证书，不代表软件需要联网。
4. 如果安全软件误报，可先停止运行并联系卖家核对文件，不建议直接关闭系统安全防护。

【免责】
本工具是本地规则/启发式文案分析工具，用来辅助拆结构、找冲突、看节奏和定位改稿方向。
