# 使用说明

## 这套工具怎么工作

```text
视频声音
  ↓
PotPlayer 的 Whisper / 语音识别（视频已有字幕时可跳过）
  ↓
原文字幕
  ↓
本项目 PotPlayer 翻译插件
  ↓
127.0.0.1:11434 本机 Ollama
  ↓
本机 Qwen 等模型
  ↓
PotPlayer 显示中文字幕
```

整个翻译链路默认只访问 `127.0.0.1`，不会把字幕上传到第三方翻译服务。

## 第一次配置

1. 确认 PotPlayer 已安装。
2. 确认 Ollama 已安装，并且本机已有一个可用模型。
3. 打开“PotPlayer本地AI实时翻译配置器.exe”。
4. 点“自动检测”。如果没找到 PotPlayer，手动选择 `PotPlayerMini64.exe` 或 `PotPlayerMini.exe`。
5. 点“刷新模型”，选中你的本地模型。
6. 点“测试翻译”。成功后说明 Ollama 与模型正常。
7. 点“一键安装 PotPlayer 翻译插件”。
8. 完全退出 PotPlayer，再重新打开。

## PotPlayer 内怎么用

### 视频本身有字幕

打开视频后，在 PotPlayer 的字幕菜单里启用“实时字幕翻译”，翻译器选择：

`本地AI实时翻译（中译）`

目标语言选择 `zh-CN`。

### 视频完全没有字幕

先启用 PotPlayer 的语音识别 / Whisper 字幕生成功能，让 PotPlayer 边播放边生成原文字幕；然后再开启上面的实时字幕翻译。

因此这套方案可以做到“边看、边识别、边翻译”，但识别速度与准确率取决于你选择的 Whisper 模型，翻译速度取决于 Ollama 模型和显卡。

## 精度建议

- 日语影视：Whisper `large-v3` 精度更高，但延迟也更高。
- 想降低延迟：可以使用 `large-v3-turbo` 或更小的模型。
- 翻译模型优先使用你本机效果稳定的 Qwen 系列。
- 本插件保留最近 6 条“原文 + 译文”作为上下文，用来改善指代、人物语气和连续对白。
- 模型启动后的第一句通常最慢，建议播放前先点一次“测试翻译”预热。

## 常见问题

### 插件列表里看不到

确认插件文件最终位于：

`PotPlayer\Extension\Subtitle\Translate\SubtitleTranslate - LocalAI Chinese.as`

然后完全退出 PotPlayer 再打开。

### 提示 Ollama 未连接

先确认 Ollama 正在运行，并且本机可以访问 `http://127.0.0.1:11434/api/tags`。

### 翻译太慢

优先换更小的翻译模型，或减少 Whisper 识别模型尺寸。9B 模型如果不能完整放进显存，会明显拖慢实时体验。

### 翻译不准

先确认“识别出来的原文”是否已经错了。语音识别错字会直接影响后面的翻译；这时应该先调 Whisper，而不是只换翻译模型。
