# PotPlayer 本地 AI 实时翻译：实机验收清单

目标：不要只看“插件能加载”，而是确认它真的能连续边看边翻译。

## A. 环境检查

先打开配置器，点“一键检查环境”。必须看到：

- `[通过] PotPlayer`
- `[通过] 翻译插件已安装`
- `[通过] Ollama 本地服务正常`
- `[通过] 模型存在`
- `[通过] 实际翻译调用成功`

任何一项未通过，先不要进入看片测试。

## B. 已有字幕模式：先单独测翻译链路

找一段自带日语字幕或外挂日语字幕的视频，连续播放 5 分钟。

记录：

```text
测试视频：
模型：
第一句等待：____ 秒
稳定后单句平均延迟：____ 秒
5分钟内漏翻：____ 次
明显错译：____ 次
人物称呼/敬语是否稳定：是 / 否
PotPlayer 是否卡顿：是 / 否
```

通过标准：

- 连续字幕能持续翻译，不出现长时间停止。
- 第一条可以慢一些，但预热后不能每句都重新等待很久。
- 重复字幕再次出现时应明显更快，因为插件有本地缓存。
- 不应频繁出现解释、分析、`<think>` 等模型废话。

## C. 无字幕模式：再测 Whisper + 翻译整链路

找一段完全无字幕的日语视频，开启 PotPlayer 的 Whisper / 语音识别字幕生成，再开启本地 AI 实时翻译。

不要把两个延迟混在一起。分别记录：

```text
说话结束 → 日文原文字幕出现：____ 秒
日文原文出现 → 中文翻译出现：____ 秒
总延迟：____ 秒
```

如果“原文出来很慢、中文出来很快”，瓶颈是 Whisper。
如果“原文出来很快、中文出来很慢”，瓶颈是 Ollama 翻译模型。

## D. 精度检查

重点看这几类句子：

1. 日语省略主语的对白。
2. 连续两个人来回说话。
3. 敬语、反问、讽刺、暧昧表达。
4. 短句和未说完的句子。
5. 人名、地点、数字等专有信息。

不要只看单句字面是否对应，要看连续 5~10 句后人物关系和语气有没有翻乱。

## E. 出问题时只反馈这 4 项

截图或复制给维护者：

```text
1. 配置器“一键检查环境”的完整日志
2. PotPlayer 版本号
3. 当前 Ollama 模型完整名称
4. 一组实际错误：日文原文 + 错误中文 + 你认为正确的大意
```

有这四项就可以继续针对性修，不需要重新描述整个环境。
