# 安卓自动讲品 MVP

目录：`tools/android-auto-sales-voice/`

这是一个纯本地 Android 自动讲品工具，目标场景是一台安卓手机对应一个实物直播间：摄像头拍商品，商品放转盘，主播不露脸，手机自动循环播报商品话术。

## 已实现

- 多商品保存、切换、删除
- 每个商品保存多段话术，一行一段
- 顺序循环 / 随机循环
- 段落间隔 0～30 秒
- TTS 语速、音量调整
- 开始 / 暂停 / 继续 / 停止
- 临时插话，插播结束后自动恢复循环
- Android 前台服务，切到视频号等直播 App 后仍保持讲品任务
- 完全本地运行，不调用云端 API，不按分钟收费
- 默认内置一组“溜溜凳”测试话术

## 最重要的实机测试

本软件负责在手机端持续输出 TTS 声音，但普通未 Root 的 Android 系统不允许一个第三方 App 直接把自己的音频流伪装成另一个 App 的麦克风输入。因此第一次测试必须实际进入直播间，从另一台设备观看直播，确认视频号能否通过手机扬声器 -> 手机麦克风的方式收进 TTS 声音。

如果直播 App 的回声消除把手机外放 TTS 压掉，后续应改用 Type-C 音频回环/声卡硬件方案，而不是继续堆软件功能。这一点决定“一台手机一直播间”能否稳定落地。

## 编译

项目使用：

- Kotlin
- Android Gradle Plugin 8.7.3
- JDK 17
- compileSdk / targetSdk 35
- minSdk 26

可用 Android Studio 直接打开本目录编译。仓库同时包含 GitHub Actions 工作流，分支更新后会自动尝试构建 Debug APK，并上传为 Actions artifact：`auto-sales-voice-debug-apk`。

## 使用

1. 安装 APK。
2. 打开后新建商品，填写商品名称。
3. 话术框中每行放一段独立讲解，建议每个商品准备 20～60 段。
4. 调整随机模式、间隔、语速和音量。
5. 点“开始”。
6. 切到视频号开播。
7. 用另一台手机进入直播间，确认实际直播声音。
8. 需要人工补一句时切回本软件，在“临时插话”中输入文字并立即插播。

## 当前版本边界

MVP 不包含自动读取直播评论、自动回复评论、自动点击商品卡、自动控制视频号界面，也不做系统级虚拟麦克风注入。先验证“后台稳定循环 + 直播间确实能收音”这两个核心条件，再决定下一版。
