生日页面接入

V1 会优先调用页面里的 window.submitBirthdayAuto(payload)。你的原生日 HTML 接进来后，只要这个函数返回结果文字或对象，就会自动念。
支持返回：字符串；或 { birthdayText, scoreText, speakText }。
