# 汽水音乐桥接服务

当前 0.1 版采用“**Kodi 插件 + 本地 qishui-api 桥接服务**”结构。原因是汽水音乐的登录、PC 搜索、App Feed 与播放接口会变化，把这层独立出来比把易变签名硬写进 Kodi 更容易维护。

## Windows 测试

双击：

`start_windows.bat`

首次会克隆公开项目 `guowenye/qishui-api`、安装 Node 依赖，并启动：

`http://0.0.0.0:3300`

Kodi 和桥接服务在同一台电脑时，插件设置保持：

`http://127.0.0.1:3300`

如果 Kodi 在电视盒子、桥接服务在电脑，把插件里的 API 地址改成电脑局域网 IP，例如：

`http://192.168.1.20:3300`

不要把 3300 端口直接暴露到公网。

## 登录说明

登录在 Kodi 插件里发起并显示二维码。当前上游二维码流程通常要求用**已登录的抖音 App**扫码确认。成功后的 sessionid 只保存在 Kodi 本机 profile 目录。
