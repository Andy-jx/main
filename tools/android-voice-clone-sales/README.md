# 自动讲品·声音复刻版

这是与 `tools/android-auto-sales-voice/` 并存的第二个 Android 应用。

- 普通版包名：`com.andyjx.autosalesvoice`
- 声音复刻版包名：`com.andyjx.voiceclonesales`
- 两个 APK 可以同时安装。

## 设计目标

1. 手机选择一段你本人或已经取得明确授权的参考声音。
2. 填写参考声音中实际说出的文字。
3. 手机把参考音频上传到局域网里的 CosyVoice 3 服务，注册成一个音色。
4. 填写直播讲品话术，每行一段。
5. 点击“一键生成并缓存全部话术”，手机把所有话术生成成 WAV 并保存到本机。
6. 开直播后直接本地循环播放缓存，不要求持续联网。
7. 临时插话时，才调用电脑端服务实时生成同一音色并立即播放。

## 为什么不是把模型直接塞进普通安卓手机

CosyVoice 3 是 0.5B 级语音生成模型，模型与运行时体积、内存和算力要求都明显高于普通 Android TTS。直播矩阵更稳的方案是：一台电脑/服务器负责生成，多台手机只缓存和播放。

## 电脑端

后端位于 `server/`。默认：

- CosyVoice 根目录：`D:\CosyVoice`
- 模型目录：`D:\CosyVoice\pretrained_models\Fun-CosyVoice3-0.5B`
- 服务端口：`8787`

需要先按官方 QwenAudio/CosyVoice 文档准备 Python 3.10 环境、依赖和 `Fun-CosyVoice3-0.5B` 模型。

在 CosyVoice 的 Python/Conda 环境中：

```bat
cd tools\android-voice-clone-sales\server
start_server.bat
```

健康检查：

```text
http://电脑局域网IP:8787/health
```

手机和电脑连接同一局域网时，把 APP 里的服务地址改成例如：

```text
http://192.168.1.8:8787
```

## 参考音频建议

- 3～15 秒优先，最长 30 秒。
- 单人说话。
- 无背景音乐、无混响、无其他人声。
- 尽量原始清晰录音。
- “参考音频里实际说的文字”必须和音频内容尽量一致。

## 直播使用顺序

1. 启动电脑端声音复刻服务。
2. APP 点“测试电脑语音服务”。
3. 选择参考音频并注册音色。
4. 写好 20～60 段讲品话术。
5. 点“一键生成并缓存全部话术”。
6. 生成完成后点“开始”。
7. 切到视频号开直播。
8. 临时需要新话术时，用“生成并立即插播”。

## 重要限制

- APK 本身不包含 CosyVoice 模型。
- 第一次注册音色、批量生成话术、临时插话需要电脑端服务在线。
- 已缓存的话术在直播循环阶段不需要电脑持续生成。
- 本工具不用于冒充他人；仅使用本人声音或已取得明确授权的声音。
