# 短剧文案拆解工具（Windows 本地版）

面向短剧、短视频创作者和对标拆解用户。把别人的文案或自己的草稿粘贴进工具，可快速查看开头钩子、结构、冲突、情绪、句段节奏、高频词、金句候选、可复用模板和针对性改写建议。

## 隐私说明

- 默认完全本地运行。
- 当前版本不调用任何远程 API，也不会上传文案。
- 没有许可服务器、账号验证或“手机回家”机制。
- 后续即使增加本地模型，也应作为可选开关，并保持默认关闭。

## Windows 安装

### 方案一：直接安装 Python 3

1. 安装 Python 3.10 或更高版本。
2. 安装时勾选 `Add Python to PATH`。
3. 本工具只使用 Python 标准库，不需要安装第三方包。
4. 下载或解压本目录后，双击 `run.bat`。

如果电脑已安装 Python，正常情况下无需执行 `pip install`。

## 运行方法

最简单：

```text
双击 run.bat
```

也可以在本目录命令行运行：

```bat
py -3 main.py
```

或：

```bat
python main.py
```

## 界面功能

1. 大文本框：直接粘贴短剧口播、分镜文案或自己的草稿。
2. `导入 .txt / .md`：支持 UTF-8、UTF-8 BOM、GB18030 常见中文文本编码。
3. `试拆示例`：自动载入内置 `sample_script.txt`。
4. `开始拆解`：运行本地规则/启发式分析。
5. 结果区：用 A–H 八个分页展示所有模块。
6. `导出报告 .md`：导出完整 Markdown 报告。
7. `导出报告 .txt`：导出完整文本报告。

## 八个拆解模块

### A. 开头钩子

取前 1–3 句，输出 0–100 分和一句针对性点评，检查悬念、冲突、利益点、情绪等因素。

### B. 结构标注

按 `钩子 → 铺垫 → 冲突 → 反转 → 催行动作` 对原文段落进行启发式标注；未识别到的结构会列为 `弱/缺失`。

### C. 冲突点列表

找出明显冲突、阻力、转折和反转句，并解释为什么属于冲突。

### D. 情绪起伏

按句标注 `正向 / 负向 / 紧迫 / 中性`，并给出如“前紧后松”“前缓后紧”“整体偏平”等节奏描述。

### E. 句段节奏

统计：

- 总字数
- 句数
- 平均句长
- 短句占比
- 长句占比
- 段落数

并提示是否过碎或过长。

### F. 高频词 Top10 + 金句候选

输出高频词，并从原文挑选 3–5 条更适合单独拿出来做标题、封面或卡点字幕的句子。

### G. 可复用模板

把当前短剧结构抽象为可再次套用的空白结构槽位。

### H. 改写建议

每次输出 3–8 条针对当前文本的修改意见，明确：

- 改哪里
- 怎么改
- 为什么改

避免只给“加强冲突”“提高节奏”这类空泛结论。

## 当前版本边界

这是离线规则/启发式工具，不是大语言模型。它适合快速做第一轮结构体检、对标拆解和改稿定位，但不会理解所有隐喻、人物关系和复杂剧情，也不保证评分等同于平台真实流量表现。
