短剧文案拆解工具｜Windows 本地AI双引擎版｜买家使用说明

【怎么打开】
1. 把整个压缩包完整解压，不要在压缩包预览里直接运行。
2. 不要只把 DramaCopyAnalyzer.exe 单独拖出来；_internal、Runtime、Models 等文件夹要一起保留。
3. 双击 DramaCopyAnalyzer.exe。
4. 买家无需安装 Python。

【两种模式】
1. 极速规则模式
- 不加载大模型，速度快。
- 适合快速看钩子、结构、冲突、情绪、节奏和改稿方向。
- 即使本地AI模型不可用，这个模式也能继续使用。

2. 本地AI深度模式
- 使用本机 llama.cpp + GGUF 大模型进行深度批改和完整改写。
- 第一次启动模型会比规则模式慢，模型越大越慢。
- 文案只在本机处理，不上传到远程 API。

【怎么用】
1. 左侧粘贴短剧/口播文案，或导入 .txt / .md。
2. 第一次可以点“试拆示例”。
3. 在“分析模式”选择极速规则或本地AI深度。
4. 点“开始拆解”查看 A–H 八模块。
5. 点“生成改写稿”得到完整稿和关键改动。
6. 点“导出 .md / .txt”保存报告。

【A–H】
A 开头钩子
B 结构标注
C 冲突点
D 情绪起伏
E 句段节奏
F 高频词/金句
G 本文结构模板
H 逐句改写建议

【本地AI设置】
正常正式成品已经把 Runtime 和 Models 配好，一般不需要改。
如果卖家让你自行选择模型，可以点“本地AI设置”：
- llama-server：选择本机 llama-server.exe
- GGUF 模型：选择 .gguf 文件
- 端口默认 18080
- 加速默认“自动”；遇到显卡兼容问题可以切“仅CPU”

【AI模式打不开/生成失败】
1. 先切回“极速规则模式”，软件仍能继续使用。
2. 确认 Runtime 和 Models 没被删除。
3. 模型太大可能导致内存/显存不足，建议换较小 GGUF。
4. 查看软件目录 ai_server.log，可提供给卖家排查。
5. 不建议为了运行本软件而关闭系统安全防护。

【隐私】
- 不调用 OpenAI、DeepSeek、Qwen 云端 API。
- 不上传你粘贴或导入的文案。
- 本地模型服务固定在 127.0.0.1 上运行。

【注意】
本地AI是大语言模型，可能出现理解错误、遗漏、重复或“自作主张”改剧情。生成稿请在试拍/发布前核对人物、事实和逻辑。
